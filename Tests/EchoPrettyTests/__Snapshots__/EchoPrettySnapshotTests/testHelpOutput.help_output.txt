[1mOVERVIEW[0m

  Consider this to be an extension of echo with support for `ANSI` codes via command line arguments.

[1mUSAGE[0m

  echo_pretty [echo flags] [options] text [options] [meta flags]

[1mOPTIONS (ECHO)[0m

  Support for [3m[4mecho[0m arguments in [3m[4mzsh[0m. To learn more: [33m[1m[3mman zshbuiltins[0m
